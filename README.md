## 📌 Project Overview

The News Headline Aggregator is an automated data pipeline designed to collect,
process, and store the latest news headlines from an external news API.

The project demonstrates how a real-world data processing workflow can be
automated using Python, Pandas, MySQL, Prefect, Jenkins, Git, and GitHub.

Instead of manually collecting and processing news data, the entire workflow
is automated from code integration to data storage.

## 🎯 Why This Project Was Chosen

This project was chosen to demonstrate practical DevOps and data-pipeline
concepts using a real-world type of automation problem.

In many organizations, data is continuously received from external sources
such as APIs, applications, IoT devices, financial systems, and business
platforms. This data needs to be collected, transformed, stored, scheduled,
and monitored reliably.

The News Headline Aggregator uses news data as a practical example of this
type of workflow.

The main objective was not only to create a Python application, but to
automate the complete lifecycle of the application using CI/CD and workflow
orchestration.

The project demonstrates:

- Source code management using Git and GitHub
- CI/CD automation using Jenkins
- Automated testing using Pytest
- Workflow orchestration using Prefect
- API data extraction using Python Requests
- Data transformation using Pandas
- Persistent storage using MySQL
- Scheduled pipeline execution
- Retry handling for temporary failures
- Duplicate data prevention
- Environment-based secret management
- Linux and AWS EC2 deployment

## 🌍 Real-World Use Case

The same architecture used in this project can be applied to many real-world
data-processing systems.

### 📰 Media and News Companies

A media organization can collect news from multiple APIs and store the data
in a centralized database for:

- Trending-news analysis
- Topic classification
- Regional news analysis
- News dashboards
- Historical analysis

### 📈 Financial Applications

The same pipeline can process:

- Stock-market data
- Financial news
- Currency information
- Company data

### 🛒 E-Commerce

The architecture can be adapted to process:

- Product information
- Product prices
- Inventory data
- Customer reviews

### 🌦️ Weather Applications

Weather APIs can be periodically collected and stored for:

- Historical weather analysis
- Forecast dashboards
- Regional monitoring

### 🏭 IoT and Monitoring Systems

The same Extract → Transform → Load approach can process data generated by
IoT devices and industrial systems.

Therefore, the News Headline Aggregator is a practical example of a more
general automated data-processing architecture.

## 🔄 Complete End-to-End Workflow

### CI/CD Workflow

1. Developer modifies the project code.
2. Developer pushes the changes to GitHub.
3. GitHub Webhook triggers Jenkins.
4. Jenkins checks out the latest source code.
5. Jenkins creates a Python virtual environment.
6. Jenkins installs project dependencies.
7. Jenkins runs automated Pytest tests.
8. Jenkins validates Python source files.
9. Jenkins connects to the News Aggregator EC2 instance using SSH.
10. Jenkins triggers the Prefect deployment.
11. Jenkins waits for the Prefect flow to complete.

### Data Pipeline Workflow

1. Prefect Worker starts the flow.
2. Extract task calls the GNews API.
3. Python Requests retrieves the latest headlines.
4. Transform task receives the API response.
5. Pandas cleans and structures the data.
6. Load task connects to MySQL.
7. SHA-256 URL hashes are generated.
8. New headlines are inserted into MySQL.
9. Existing headlines are skipped using the UNIQUE URL hash.
10. Prefect records the final flow state.

### Automated Schedule

The Prefect deployment is configured with:

- Schedule: Every day
- Time: 9:00 AM
- Timezone: Asia/Kolkata
- Cron: `0 9 * * *`

This allows the pipeline to execute automatically without manual
intervention.
